# Frontier concepts

Frontier全体、下位World群およびAdventure／Exploration Contentの非正本Conceptを索引します。ここに掲載された文書は正式な現行Frontier仕様ではなく、Plugin取得、World生成、Runtime変更またはRelease Scopeを承認しません。

## Current design input

- [Frontier_Server_Specification_V0.0.5.md](Frontier_Server_Specification_V0.0.5.md)
  - Frontier全体と、下位World群や共通境界を横断する上位Conceptです。
  - Worlds BeyondはOverworld単一World、Ruined FrontierはOverworld／Nether／End構成とします。
  - 正式な現行Frontier仕様ではありません。
- [Worlds_Beyond_Specification_V0.0.6.md](Worlds_Beyond_Specification_V0.0.6.md)
  - Iris Overworldだけを使用する探索・観光Worldの構想です。
  - Iris Nether／Endは採用しません。
  - Iris Engineの導入、取得、World生成またはRelease Scopeを承認しません。
- [Ruined_Frontier_Specification_V0.0.5.md](Ruined_Frontier_Specification_V0.0.5.md)
  - BetterStructuresとEliteMobsを使用するOverworld／Nether／End World群の構想です。
  - BetterStructuresまたはEliteMobsの導入・取得を承認しません。

実装には、採用範囲を明示し、ユーザーが現在のSessionで割り当てた専用`codex/`指示書が必要です。
